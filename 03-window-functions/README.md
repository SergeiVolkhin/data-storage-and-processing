# Модуль 03. Группировка данных и оконные функции

## Цель

Научиться группировать и агрегировать данные, считать на их основе показатели
и решать аналитические задачи с помощью оконных функций.

## Задачи

На тех же данных интернет-магазина решаются 8 запросов:

1. Распределение клиентов по сферам деятельности, отсортированное по убыванию.
2. Сумма дохода (`list_price * quantity`) по подтверждённым заказам за каждый
   месяц в разрезе сфер деятельности.
3. Число уникальных онлайн-заказов по каждому бренду среди подтверждённых
   заказов IT-клиентов, включая бренды с нулём заказов.
4. По каждому клиенту: сумма, максимум, минимум, количество и средняя сумма
   заказа — двумя способами (`GROUP BY` и оконные функции) с сравнением.
5. Клиенты с топ-3 минимальной и топ-3 максимальной суммой транзакций
   (клиенты без заказов учитываются с суммой 0).
6. Только вторые транзакции клиентов — через оконные функции; клиенты с менее
   чем двумя транзакциями исключаются.
7. Максимальный интервал в днях между последовательными заказами клиента;
   клиенты с одним заказом исключаются.
8. Топ-5 клиентов по доходу в каждом сегменте благосостояния.
