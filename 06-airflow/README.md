# Модуль 06. Автоматизация расчётов в Apache Airflow

## Цель

Научиться писать DAG в Apache Airflow для автоматизации регулярных расчётов.

## Что сделано

DAG ежедневно прогоняет полный конвейер обработки данных интернет-магазина:

1. Параллельно загружает четыре CSV-файла (клиенты, продукты, заказы и их
   состав) в соответствующие таблицы PostgreSQL.
2. Параллельными задачами выполняет два аналитических запроса — клиенты с топ-3
   минимальной и максимальной суммой транзакций и топ-5 клиентов по доходу
   в каждом сегменте благосостояния — и сохраняет результаты в отдельные файлы.
3. Проверяет, что запросы вернули непустой результат; при провале проверки
   отправляет уведомление на почту.
4. Завершается сообщением об успешном или неуспешном выполнении DAG.
