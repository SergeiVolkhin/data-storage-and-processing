# Модуль 02. Основные операторы PostgreSQL

## Цель

Освоить базовые операторы PostgreSQL: фильтрацию по разным условиям, вложенные
запросы, объединение таблиц.

## Задачи

Данные интернет-магазина (клиенты, продукты, заказы и их состав) загружаются
в PostgreSQL, после чего решаются 8 запросов:

1. Уникальные бренды с продуктом дороже 1500 $ по стандартной стоимости
   и суммарными продажами не менее 1000 единиц.
2. По каждому дню с 2017-04-01 по 2017-04-09 — число подтверждённых
   онлайн-заказов и уникальных клиентов.
3. Профессии клиентов: из IT с должностью на «Senior» и из Financial Services
   на «Lead», для клиентов старше 35 лет; выборки объединены через `UNION ALL`.
4. Бренды, купленные клиентами из Financial Services, но не купленные
   клиентами из IT.
5. Топ-10 клиентов по числу онлайн-заказов брендов Giant / Norco / Trek
   Bicycles среди активных клиентов с оценкой имущества выше средней по штату.
6. Клиенты без подтверждённых онлайн-заказов за последний год, владеющие
   автомобилем, с сегментом благосостояния не Mass Customer.
7. Клиенты из IT, купившие 2 из 5 самых дорогих продуктов линейки Road.
8. Клиенты из IT или Health с тремя и более подтверждёнными заказами
   за 2017-01-01 — 2017-03-01 и общим доходом свыше 10 000 $; группы
   объединены через `UNION`.

## Что внутри

- [`schema/schema.sql`](schema/schema.sql) — создание таблиц и подготовка данных.
- [`reports/script.sql`](reports/script.sql) — решения всех 8 запросов.
- [`reports/screenshots/`](reports/screenshots/) — результаты выполнения запросов.
- [`data/`](data/) — исходные CSV.
