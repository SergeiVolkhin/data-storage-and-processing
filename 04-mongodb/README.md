# Модуль 04. Выборка и агрегация данных в MongoDB

## Цель

Освоить основные приёмы работы с MongoDB: выборку, сортировку, объединение
и агрегацию документов, а также передачу результатов в Python для дальнейшего
анализа.

## Что сделано

На датасете `sample_mflix` (фильмы, MongoDB Atlas) выполнены запросы на выборку
по условиям и построен конвейер обработки через фреймворк агрегации MongoDB.
Подключение к базе и запросы выполняются из Python с помощью PyMongo, результаты
разбираются в ноутбуке.

## Что внутри

- [`homework.ipynb`](homework.ipynb) — запросы к MongoDB и разбор результатов.
- [`requirements.txt`](requirements.txt) — зависимости (PyMongo, pandas,
  matplotlib).

## Как запустить

Нужен доступ к кластеру MongoDB с загруженным датасетом `sample_mflix` —
бесплатный кластер уровня M0 в MongoDB Atlas с опцией Load Sample Dataset либо
локальная MongoDB. Строка подключения указывается в ноутбуке.

```bash
pip install -r requirements.txt
jupyter notebook
```
