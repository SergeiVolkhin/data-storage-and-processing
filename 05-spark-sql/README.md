# Модуль 05. Анализ данных на Spark SQL

## Цель

Научиться работать с основными операторами Spark SQL: фильтрацией, вложенными
запросами, объединением таблиц и оконными функциями на больших данных.

## Задачи

Из CSV с логами бронирований отеля создаётся таблица, дополнительно
генерируется таблица-календарь со всеми датами за 2017–2018 годы. На этих
данных решаются запросы:

1. Среднее число ночей проживания для подтверждённых броней с разбивкой
   по месяцам и годам.
2. Топ-3 месяца 2018 года по доле отменённых броней.
3. Среднее время между бронированием и заездом по месяцам.
4. Средняя выручка по месяцам и годам в разрезе типов бронирования — в виде
   сводной таблицы (`PIVOT`).
5. Топ-5 постоянных гостей по выручке и их доля в общей выручке от постоянных
   гостей.
6. Число гостей по каждому дню с расчётом загрузки отеля (вместимость 400),
   включая дни без гостей.
